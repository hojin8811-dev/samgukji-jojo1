# ⚔️ 삼국지 조조전 · 천하의 서막

전국 지도에서 내정을 다스리고, 출진하면 조조전 스타일의 턴제 격자 전장으로 들어가는
하이브리드 전략 시뮬레이션 웹게임입니다.

- **모바일 우선** — 412×915 세로 화면에서 전장과 명령창이 스크롤 없이 한눈에 들어옵니다.
- **코에이 조조전풍 아트** — 무장 초상화 · 전장 배경 · 병과 스프라이트를 일러스트로 생성해 사용합니다.
- **정적 웹** — `index.html` + `style.css` + `game.js` + `assets/` 만으로 GitHub Pages에서 바로 동작합니다.

## 화면

1. **타이틀** — 조조 초상화와 전국 지도 아트 위에 三國志 曹操傳.
2. **전국 지도 · 내정** — 양피지풍 삼국지대 지도 위에 도시 깃발 마커. 도시를 눌러 징병 · 훈련 · 개발 · 장수 배치.
3. **격자 전장** — 성벽·강물·숲·산지가 그려진 탑다운 전장 위에서 유닛을 움직이고 싸웁니다.

## 플레이 방법

1. 지도에서 도시를 눌러 내정합니다. (징병 · 훈련 · 개발 · 장수 배치)
2. 인접한 적 도시를 고르고 **출진**하면 전장으로 들어갑니다. 전장 개시 연출 → 무장 대사 → 전투.
3. 아군을 눌러 파란 타일로 이동하고, 붉게 빛나는 적을 눌러 공격합니다.
4. 풍수사 순유의 **소보급 · 대보급 · 고무 · 풍수**, 조조의 **지휘**로 전황을 뒤집습니다.
5. 적을 모두 격파하면 지도로 돌아와 영토가 넓어집니다. (5거점 평정 = 천하통일)

## 조조전식 연출

- **전장 개시 카드** — 「여남 공방전 · 황건 잔당 토벌」이 인장과 함께 화면에 뜹니다.
- **대사창** — 화면 하단에 무장 초상화 + 이름 · 병과 · 고전 대사창. 터치로 넘깁니다.
- **유닛 정보창** — 초상화, 병과, 무력 · 지력 · 통솔, 공 · 방 · 이동, HP · MP, 현재 지형과 지형 보정.
- **적 장수 목록** — 남은 적 장수를 초상화와 HP 바로 확인하고 눌러 정보를 봅니다.
- **전투 이펙트** — 참격 궤적 · 화살 궤적 · 회복 빛 · 화계 불꽃 · 데미지 숫자 · 화면 흔들림.

## 병과와 지형 상성

| 병과 | 장수 | 특징 |
| --- | --- | --- |
| 군웅 | 조조 | 지휘(주변 아군 공격 +20%) · 균형 |
| 기병 | 하후돈 | 이동 6 돌격, 숲 3·산지 통행 불가 |
| 궁기병 | 하후연 | 대각선 포함 3칸 사격, 산지에서 사거리 +1 |
| 풍수사 | 순유 | 소·대보급, 고무, 풍수(적 방어 -25%) |
| 보병 | 조홍 | 높은 방어, 성문 수비에 적합 |
| 산적 | 주창(적) | 산지·숲 이동 1, 공격 +25%, 회심 증가 |
| 수적 | 주태·수적 두목(적) | 강물 통행, 수전에서 공격 +20% |
| 책사 | 황건 술사(적) | 화계 — 방어 무시 피해 |

- 평지 / 도로 / 숲 / 산지 / 강물 / 여울 / 다리 / 성문 / 성벽 9종 지형. 병과별 이동 비용과 방어 보정이 다릅니다.
- 공격 후 사거리 안이면 반격합니다. 원거리에서 일방적으로 쏘면 반격을 피할 수 있습니다.

## 전장

1. **여남 공방전** — 좌상단 숲, 화면을 가르는 강과 중앙의 외나무다리, 우하단 산맥. 주창(산적) · 주태(수적) · 황건 잔당.
2. **건업 수전** — 온 화면을 채우는 큰 강과 좌우 두 다리. 수적 두목과 수군. 수적만 물 위를 걸을 수 있습니다.
3. **업성 공략** — 오른쪽으로 기우는 성벽과 성문. 성문을 지키는 황건 두목과 책사.

## 파일 구조

```
index.html            화면 골격 (지도 / 전장 / 모달 / 타이틀)
style.css             금테 패널 · 세로/가로 반응형
game.js               데이터(병과·지형·전장), 전투 규칙, AI, 렌더링, 진행
assets/portraits/web  무장 초상화 256px WebP (장수 9 + 병과 4)
assets/maps/web       전국 지도 · 전장 배경 WebP (12×10 타일에 맞춘 지형도)
assets/sprites/web    병과 스프라이트 WebP (아군/적군 색 변형)
assets/_source        생성 원본 PNG (배포 제외, .gitignore)
tools/                아트 생성·가공 스크립트와 브라우저 검증 스크립트
```

## 진행 저장

전투 결과 · 내정 · 장수 레벨은 브라우저 `localStorage`에 저장됩니다.
타이틀의 **이어서 하기**, 또는 지도 우측 상단 **☰ → 처음부터**로 초기화할 수 있습니다.

## 로컬 실행

`index.html`을 브라우저로 열거나, 폴더에서 `python3 -m http.server` 후 접속하면 됩니다.
