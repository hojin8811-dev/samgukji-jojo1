- **인구 기반 징병**: 성마다 인구가 있고(대도시 52,000 · 소도시 33,000 · 관문/요새 14,000 내외) 징병은 인구에서 병사를 빼옵니다. 주둔병 상한은 **인구의 30%**, 징병하면 민심 -5. 민심 70 이상이면 세수·인구가 더 늘고 40 아래면 줄어듭니다. 관문·요새는 인구·수입이 도시의 40~45%인 대신 성벽이 더 단단합니다.
- **여섯 시설 내정**: 관아(민심·군사 임명) · 농장(개간) · 시장(상업) · 병영(징병·훈련) · 주점(그 성의 인재만 등용) · 성벽(보수). **군사 위임**을 쓰면 남은 장수들의 행동력으로 내정을 자동 처리합니다. 등용한 장수는 그 달을 바로 마칩니다.
- **장수 명부**: `장수 / 보물 / 배치` 탭, `이름·통솔·무력·지략·정치·매력·충성·직책·위치` 표, 머리글 탭 정렬, 행을 누르면 상세·장비·이동.
- **전투 밸런스**: 병력 수(`hp/maxHp` + 절대 병력)가 공격력에 직접 반영되고, 무력·지력의 영향은 낮췄습니다. 병과 상성·지형·보물·책략의 비중이 커졌습니다.
- **오디오**: 컨텍스트를 하나로 합치고, 배경음은 오프라인으로 미리 렌더한 루프 버퍼로 재생합니다. 효과음은 동시 발음 수 상한과 연타 솎아내기로 끊김을 없앴고, 화면이 가려지면 절전 정지합니다.

## v3 업데이트 — 실제 플레이 피드백 반영

- **내정 행동력**: 주둔 장수 1인당 한 달 1회 행동. 화면에 `행동 가능 장수 n/m`과 장수별 대기/완료 표시, 남은 장수가 없으면 명령이 잠깁니다. `다음 달`에 전원 회복.
- **내정 연출**: 명령을 내리면 장수 초상화 컷인 + 한국어 대사 + 해당 거점(관아·농장·시장·병영) 위로 `+군량/+금` 파티클이 뜹니다. 계절 이벤트 24종(`data/domestic_events.json`)이 월정산에 카드로 등장해 금·군량·병력·민심을 바꿉니다.
- **전장 이동**: BFS 최단 경로를 계산해 한 칸씩 걷는 애니메이션(카메라 부드러운 추적, 발소리)으로 이동합니다. 순간이동 없음.
- **전투 연출**: 근접은 돌진+베기 궤적, 궁수·궁기·연노병은 화살/철노, 포차·발석차는 석탄 투척, 책사·풍수사·도사·무희·군악대는 마법진·불길·회복 오라. 피격 시 붉은 섬광·흔들림·피해 숫자.
- **전투 예고**: 사거리 안의 적을 누르면 예상 피해·반격 피해·지형 방어·인연 배지를 먼저 보여주고 `공격!`으로 확정합니다. 방어자가 사거리 안이면 반격합니다.
- **인연·숙적 40쌍**(`data/bonds.json`): 아군 인연이 2칸 안에 있으면 공격 +15%(금빛 `緣` 연결선·전장 기록), 숙적이 맞붙으면 피해 +20%와 일기토 콜아웃. 조조의 숙적은 등용을 거부합니다.
- **관작·대사**(`data/quotes_and_ranks.json`): 명성에 따라 `현령`~`황제` 10단계, 상단 HUD에 계절(춘·하·추·동)과 관작 표시, 매달 `salaryGold` 봉급 지급. 장수별 내정·출진·승리·퇴각 대사가 컷인과 전장 연출에 쓰입니다.
- **전용 일러스트 40종**(`data/top100_art_manifest.json`): 초상화·SD 스프라이트가 병과 공용 그림보다 우선 적용됩니다.
- **사운드**: Web Audio로 합성한 효과음(발소리·칼소리·활시위·법진·승리 팡파르)과 5테마 BGM(`js/bgm.js`). 상단 `♪` 버튼으로 한 번에 끄고 켜며 설정이 저장됩니다.
- **세력 일관성**: 도시 주둔 장수는 그 성의 세력 장수로만 채웁니다(관우가 여포와 같은 성에 서지 않음). 인재 탐색은 위 세력과 멸망 세력의 망명 장수만 보여주고, 조조의 숙적은 `등용 거부`로 표시됩니다.
- **부드러운 터치**: 지도·전장 팬에 관성(velocity + 0.92 마찰) 적용, 목록 패널은 `overscroll-behavior: contain` 모멘텀 스크롤.

## 4단계

1. **천하 지도** — 78개 거점(대도시·소도시·관문·요새)을 핀치·드래그로 누비는 인터랙티브 지도. 내 성은 내정, 적성은 정보→출진.
2. **내정** — 성내 일러스트와 8개 명령(개간·상업·징병·훈련·인재·보수·출진·지도). 인재 탐색으로 499명 중 원하는 장수를 등용.
3. **인물·장비** — 코어 6명 전용 초상화·SD. 499명은 병과별 초상화/SD를 공유. 보물 150종을 무기·방어구·명마·병법서 4슬롯에 장착.
4. **전장** — 공성·수전·산전·요새 4종의 18×18 스크롤 격자. 병력이 곧 HP, 최대 10부대 편성. 이동·공격·책략·군량·턴 종료.

## 핵심 시스템

- **병력 = HP**: 성에서 징병한 병력을 부대에 배정. 명장 1인 1,600~4,800, 병종 부대 1,700~2,600. 승리하면 잔존 병력이 점령지 수비병이 됩니다.
- **대군 출진**: 명장 + 일반 병종 부대(검병대·궁수대·기병대·산적대·수적대·포차대…)를 섞어 최대 10부대.
- **18 병과 · 전장 상성**: 수적은 수전 +30%, 산적·야수병은 산전 +25%, 포차는 공성 +35%, 궁수·등갑병은 요새 +20% 등. 병과 데이터는 `data/classes.json`.
- **경험치 · 승급**: 전투·훈련으로 EXP. Lv.5/10/20/30에서 4단계 승급(예: 궁기 → 궁기병 → 유성궁기 → 비장궁기 → 신궁기병), 공격·방어 +10%, 책략 해금.
- **보물 150종**: 등급(전설/영웅/희귀), 스탯 보정, 적장·도시 기반 드랍.
- **이벤트 30종**: 호로관의 여포, 장판교의 조운 등 도시·장수 매칭 시 「緣」 이벤트 카드 연출.
- **시나리오 4종**: 190 반동탁·200 관도·208 적벽·220 IF 총력전. 수도 기준으로 78개 거점 소유가 다시 칠해집니다.
