# ⚔️ 삼국지 조조전 · 천하의 서막 (1단계 프로토타입)

전국 지도에서 내정을 다스리고, 출진하면 조조전 스타일의 턴제 격자 전장으로 들어가는
하이브리드 전략 시뮬레이션 웹게임의 1단계(MVP) 프로토타입입니다.

- **모바일 우선** — 안드로이드 폰 세로/가로 화면, 한 손가락 터치 조작
- **외부 의존성 없음** — 이미지·사운드 파일 없이 Canvas/SVG/Web Audio로 자체 완결
- **정적 웹** — `index.html` + `style.css` + `game.js` 만으로 GitHub Pages에서 바로 동작

## 플레이 방법

1. 지도에서 도시를 눌러 내정합니다. (징병 · 훈련 · 개발 · 장수 배치)
2. 인접한 적 도시를 고르고 **출진**하면 전장으로 들어갑니다.
3. 아군을 눌러 파란 타일로 이동하고, 붉게 빛나는 적을 눌러 공격합니다.
4. 풍수사 순유의 **소보급 · 대보급 · 고무 · 풍수**, 조조의 **지휘**로 전황을 뒤집습니다.
5. 적을 모두 격파하면 지도로 돌아와 영토가 넓어집니다. (5거점 평정 = 천하통일)

## 병과와 지형 상성

| 병과 | 장수 | 특징 |
| --- | --- | --- |
| 군웅 | 조조 | 지휘(주변 아군 공격 +20%) · 균형 |
| 기병 | 하후돈 | 이동 6 돌격, 숲 3·산지 통행 불가 |
| 궁기병 | 하후연 | 대각선 포함 3칸 사격, 산지에서 사거리 +1 |
| 풍수사 | 순유 | 소·대보급, 고무, 풍수(적 방어 -25%) |
| 보병 | 조홍 | 높은 방어, 성문 수비에 적합 |
| 산적 | 주창(적) | 산지·숲 이동 1, 공격 +25%, 회심 증가 |
| 수적 | 주태(적) | 강물 통행, 수전에서 공격 +20% |
| 책사 | 황건 술사(적) | 화계 — 방어 무시 피해 |

- 평지/도로/숲/산지/강물/다리/성문/성벽 8종 지형, 병과별 이동 비용과 방어 보정이 다릅니다.
- 공격 후 사거리 안이면 반격합니다. 원거리에서 일방적으로 쏘면 반격을 피할 수 있습니다.

## 전장

1. **여남 공방전** — 산지·숲·강물·다리. 주창(산적) · 주태(수적) · 황건 잔당
2. **건업 수전** — 넓은 강과 두 개의 다리. 수적 두목과 수군
3. **업성 공략** — 성벽과 성문. 황건 두목과 책사

## 진행 저장

전투 결과·내정·장수 레벨은 브라우저 `localStorage`에 저장됩니다.
타이틀 화면의 **이어서 하기**, 또는 지도 우측 상단 **☰ → 처음부터**로 초기화할 수 있습니다.

## 파일 구조

```
index.html   화면 골격 (지도 화면 / 전장 화면 / 모달)
style.css    금테 패널·도트 감성·세로/가로 반응형
game.js      데이터(병과·지형·전장), 전투 규칙, AI, 렌더링, 캠페인 진행
```

## 로컬 실행

`index.html`을 브라우저로 열면 바로 동작합니다. (서버 없이 file:// 가능)
